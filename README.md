# Nat-Multi Tools (Vercel Version)

## Cara Deploy ke Vercel

1. Buat repository di GitHub dan upload semua file ini:
   - main.py
   - nat-multi-tools.html
   - requirements.txt
   - vercel.json

2. Buka [vercel.com](https://vercel.com) → Login dengan GitHub

3. Klik **Add New** → **Project**

4. Import repository yang berisi file-file di atas

5. Biarkan setting default, lalu klik **Deploy**

6. Setelah selesai, buka URL yang diberikan Vercel.

## Peringatan Penting

- Vercel **sangat tidak ideal** untuk yt-dlp karena timeout pendek dan tidak ada FFmpeg.
- Video besar hampir pasti gagal.
- Lebih cocok dicoba untuk **audio** atau video kecil.
- Jika sering gagal, lebih baik pakai Render atau tool online yang sudah jadi.
